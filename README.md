# 🍽️ Restaurant Table Allocation System

A web-based restaurant table reservation and management system built using Flask and SQLite.

## 🌐 Live Demo

👉 https://restaurant-table-allocation.onrender.com

## 📌 Features

- Customer Registration & Login
- Admin Login
- Table Availability
- Table Booking
- Booking History
- Admin Dashboard
- Table Management
- Secure Password Hashing
- SQLite Database

## 🛠️ Technologies Used

- Python
- Flask
- SQLite
- HTML
- CSS
- JavaScript
- Bootstrap

## 🚀 Deployment

Deployed using Render.
